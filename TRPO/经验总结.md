# TRPO 双环境实验总结

## 1. 目录结构

本项目按动作空间把两个实验拆开：

```text
TRPO/
├── CartPole/
│   ├── config.py
│   ├── environment.py
│   ├── networks.py
│   ├── agents.py
│   ├── trainer.py
│   ├── visualization.py
│   ├── rl_utils.py
│   ├── main.py
│   └── practice.py
└── Pendulum/
    ├── config.py
    ├── environment.py
    ├── networks.py
    ├── agents.py
    ├── trainer.py
    ├── visualization.py
    ├── rl_utils.py
    └── main.py
```

两个 case 共用 TRPO 的数学思想，但不共用策略网络，因为动作空间不同：

| Case | 环境 | 动作空间 | 策略分布 |
| --- | --- | --- | --- |
| CartPole | `CartPole-v1` | 离散 | `Categorical` |
| Pendulum | `Pendulum-v1` | 连续 | `Normal` |

不能只把 `ENV_NAME` 改成另一个环境。连续动作环境需要从策略网络输出高斯分布的均值和标准差，并按动作维度计算 log probability 和 KL 散度。

## 2. TRPO 的公共流程

两个版本都执行以下流程：

```text
当前策略采样完整 episode
    ↓
critic 计算 TD target 和 TD error
    ↓
使用 GAE 估计 advantage
    ↓
计算 surrogate objective 的梯度
    ↓
共轭梯度法求近似自然梯度方向
    ↓
Hessian-vector product 计算曲率
    ↓
按 KL 约束缩放更新方向
    ↓
线性搜索确认目标变好且 KL 不超限
    ↓
更新 actor 和 critic
```

TRPO 的核心约束是：

$$
\max_\theta L(\theta)
\quad
\text{s.t.}
\quad
\bar{D}_{KL}(\pi_{old}\|\pi_\theta)\leq \delta
$$

其中 actor 的更新由 KL 信任域限制，critic 使用 Adam 拟合状态价值函数。

## 3. CartPole 实现

CartPole 使用离散策略：

```python
probs = actor(states)
action_dist = torch.distributions.Categorical(probs)
```

策略网络输出每个动作的概率，动作通过分类分布采样。

运行：

```bash
cd CartPole
python main.py
```

## 4. Pendulum 实现

Pendulum 使用连续策略：

```python
mean, std = actor(states)
action_dist = torch.distributions.Normal(mean, std)
```

策略网络输出：

- `mean`：通过 `tanh` 映射到环境动作范围。
- `std`：通过 `softplus` 保证为正。

动作采样后裁剪到环境边界。对于一维 Pendulum 动作，策略 log probability 和 KL 散度都需要沿动作维度求和。

Pendulum 的 reward 范围通常为负数。当前实现使用：

```python
scaled_rewards = (rewards + 8.0) / 8.0
```

只对 critic 的 TD 更新进行缩放，训练日志仍记录原始 reward。

运行：

```bash
cd Pendulum
python main.py
```

## 5. 与原文实验结果对照

原文使用的实验结果：

| Case | 原文环境 | 回合数 | 原文末段平均回报 |
| --- | --- | ---: | ---: |
| CartPole | `CartPole-v0` | 500 | 约 `200` |
| Pendulum | `Pendulum-v0` | 2000 | 约 `-296.363` |

当前代码单次运行结果：

| Case | 当前环境 | 回合数 | 当前末 10 回合平均回报 |
| --- | --- | ---: | ---: |
| CartPole | `CartPole-v1` | 500 | `137.700` |
| Pendulum | `Pendulum-v1` | 2000 | `-289.503` |

### Pendulum 对比

当前 `-289.503` 与原文 `-296.363` 接近，说明连续动作 TRPO 的主要实现路径是匹配的：

- 高斯策略输出正常。
- 连续动作能够传入环境。
- GAE、KL 约束、共轭梯度和线搜索能够完成训练。
- reward scaling 没有破坏最终原始回报的统计。

Gymnasium 的 `Pendulum-v1` 与原文旧版 `Pendulum-v0` 存在版本差异，因此数值不会完全一致。单个随机种子也不足以说明算法优劣。

### CartPole 对比

当前 `137.700` 低于原文 `200`，但两者不是完全可比的实验：

- 原文使用 `CartPole-v0`，单回合最大回报通常为 200。
- 当前使用 `CartPole-v1`，单回合最大回报通常为 500。
- 原文的 `200` 实际上同时也是旧环境的时间上限。
- 当前结果 `137.7` 表示平均能坚持约 138 步，尚未达到稳定解决任务的水平。

因此，CartPole 结果说明当前实现可以训练，但还没有复现原文中“达到回合上限”的表现。可能原因包括：

1. `CartPole-v0` 和 `CartPole-v1` 的时间上限不同。
2. Gymnasium 版本、初始化方式和环境随机性不同。
3. 当前只运行了一个随机种子。
4. TRPO 的 KL 约束、critic 学习率和线搜索参数对离散环境较敏感。
5. 当前训练代码使用 `terminated or truncated` 结束 episode；这符合 Gymnasium 交互，但会把时间截断作为训练结束处理。

## 7. 后续实验建议

### 7.1 先统一比较条件

为了公平比较原文结果，可以单独建立对照配置：

- 都使用当前 Gymnasium 版本。
- 都使用明确的 episode 上限。
- 都使用相同随机种子集合。
- 都记录最后 10 或 20 个 episode 的平均回报。

### 7.2 CartPole 调参方向

可以优先尝试：

- 增大 `NUM_EPISODES`。
- 调整 `KL_CONSTRAINT`。
- 调整 `CRITIC_LR`。
- 增加共轭梯度迭代次数。
- 对多个随机种子取均值。

### 7.3 Pendulum 调参方向

Pendulum 当前已经接近原文结果，可以进一步观察：

- 回报移动平均是否稳定上升。
- KL 散度是否经常触及约束上限。
- 动作是否长期饱和在边界。
- reward scaling 对 critic loss 的影响。

## 8. 总结

这次整理的关键不是把两个环境的入口复制两份，而是明确动作空间决定策略分布：

- 离散动作使用 `Categorical`。
- 连续动作使用 `Normal`。
- TRPO 的信任域优化步骤可以复用。
- 网络输出、log probability、KL 计算和动作处理必须按动作空间分别实现。

当前 Pendulum 结果已基本复现原文量级；CartPole 仍需在统一环境版本和多随机种子条件下继续调参，不能仅凭一次 `137.700` 判断 TRPO 实现失败。
