# SAC 超参说明与灵敏度实验设计（HalfCheetah-v5）

目标：画出一张**可解释的灵敏度图**——回答“每个超参是什么、在算法的哪一步起作用、动它会怎样、本任务对它敏不敏感、为什么”。
不追求找到更好的配置。基线（lr 3e-4 / γ 0.99 / τ 0.005 / batch 256 / target entropy -6 / UTD 1 / 初始 alpha 0.01 / hidden 256 / reward scale 1）
是 SAC 论文和 SB3 在 MuJoCo 上调出来的默认值，已经在局部最优附近；从它出发做扰动，**大多数方向变差是正常结果，不是实验失败**。
变差的方式（多快、哪一侧、是否对称）才是灵敏度图要给你的信息。

## 0. 先用 SAC 的四个公式把“超参在哪起作用”钉住

```text
critic 目标      y = r/s + γ·(1-d)·( min(Q1', Q2')(s', a') − α·log π(a'|s') ),   a' ~ π(·|s')
critic 损失      L_Q = MSE(Q_i(s,a), y)，Adam 学习率 lr_critic，batch 大小 B
target 网络      θ' ← (1-τ)·θ' + τ·θ                      （每次更新后一次）
actor 损失       L_π = E[ α·log π(a|s) − min(Q1,Q2)(s,a) ]，Adam 学习率 lr_actor
温度损失         L_α = −log α · ( log π(a|s) + H_target )，Adam 学习率 lr_alpha，初值 α0
```

其中 `s` 是 reward scale（代码里把 reward 除以它），`d` 只在真终止时为 1（HalfCheetah 永远不终止，1000 步截断时仍 bootstrap）。
每个环境步做 `UTD` 次“采样 batch → 更新 critic → 更新 actor → 更新 α → soft update”。

## 1. 逐超参说明

每项包含：**是什么 / 作用 / 太小 / 太大 / 本任务的预期 / 本实验怎么测**。
“预期”是我在看到数据之前写下的预测（预注册），不是事实；§3 的表留了你自己的预测列，请**先填再看结果**。

### 1.1 学习率 lr（actor = critic）

- **是什么**：Adam 的步长。本实验把 actor 和 critic 绑成同一个值。
- **作用**：critic 要把 Q 从 0 拟合到几百甚至上千；actor 要跟着 Q 变化。步长决定它们追目标的速度。
- **太小**：每次更新走得短，曲线整体向右平移（已观察到 1e-4 约比基线慢 1.8 倍）。
- **太大**：critic 的拟合目标本身是自己的 bootstrap（deadly triad），步长过大会让 Q 来回震荡、高估；actor 追着震荡的 Q，策略抖动。
  Adam 的步长有界（≈lr），所以更常见的表现是“曲线噪声大、偶发回退”，而不是立刻 NaN。
- **预期**：倒 U 形。早期指标在 6e-4–1e-3 最好；后期指标在 3e-4–1e-3 区间内基本平；3e-3 在两个指标上都不会好过 1e-3，跨 seed 方差变大。
  （依据：已有数据 1e-3 早期领先 51%、后期被追平。）
- **网格**：1e-4*, 3e-4（基线）, 6e-4, 1e-3*, 3e-3（带 * 的已有结果）。

### 1.2 折扣因子 γ

- **是什么**：未来回报的折现。有效视野 ≈ 1/(1-γ) 步；本环境控制步长 0.05 s，γ=0.99 ≈ 100 步 ≈ 5 s，γ=0.95 ≈ 20 步 ≈ 1 s。
- **作用**：决定 critic 看多远；同时决定 Q 的量级 ≈ r/(1-γ)。
- **太小**：近视。HalfCheetah 的 reward 每步都有（前进速度 − 控制代价），但周期性步态需要跨多步协调，短视野下“现在多用力、几步后才变快”的动作被低估。
- **太大**：Q 量级变大、bootstrap 链变长，误差累积更久，critic 在固定学习率下更难拟合；同时温度与 Q 的相对尺度变了。
- **预期**：单调上升后饱和，高端轻微回落：0.9 < 0.95 < 0.99 ≈ 0.995 ≥ 0.998。0.9 比 0.95 更差（大概率）；0.995 与基线在噪声内；0.998 持平或略低，且早期更慢。
  这是**我最没把握的一项**——0.995 是否带来可见增益取决于步态学习是否真的受视野限制。
- **混杂（要记住）**：γ 同时改变了 Q 的量级和 α 的相对重要性，本实验不拆开，因此对 γ 的解释永远带一个“Q 尺度”的备注。
- **网格**：0.9, 0.95*, 0.99（基线）, 0.995, 0.998；横轴用有效视野 1/(1-γ)（对数）。

### 1.3 target 平滑系数 τ

- **是什么**：target 网络每步向 online 网络靠拢的比例。target 滞后 ≈ 1/τ 次更新：0.001 ≈ 1000 次，0.005 ≈ 200 次，0.02 ≈ 50 次，0.1 ≈ 10 次。
- **作用**：把 critic 的回归目标“固定”一段时间，缓解 bootstrap 目标自己追自己的不稳定。
- **太小**：目标很稳，但新学到的价值信息要很久才传回来，早期学习变慢。
- **太大**：target ≈ online，退化成“没有 target 网络”，目标随每次更新抖动，容易高估和发散。SAC 的 min(Q1,Q2) 提供了一层保护，所以不会立刻坏。
- **预期**：平台 + 右侧悬崖：0.001 早期更慢；0.005–0.02 在噪声内；0.1 明显更差或更不稳定，是本实验里**最可能出现发散 seed 的位置**。
- **网格**：0.001, 0.005（基线）, 0.02, 0.1。

### 1.4 目标熵 H_target（以及它决定的稳态策略随机性）

- **是什么**：温度 α 的自动调节目标。α 会被推到“让平均策略熵 ≈ H_target”。默认 −dim(A) = −6 是经验启发式，不是理论值。
- **作用**：控制训练期的探索量。评估用的是确定性 `tanh(μ)`，所以它**只通过“训练数据质量”间接影响评估**。
- **更低（-12）**：策略更早变窄、更确定，早期可能更快；风险是探索不足、后期落入局部步态。
- **更高（-3, 0）**：训练动作更随机；0 附近几乎一直在噪声里采样，学得慢。
- **预期**：100k 步内大致单调——越低越好或持平，到 −12 为止；0 明显更差（>20% 的损失）；−3 轻微更慢。看不到“探索不足”的代价，因为它多半出现在 1M 步。
- **网格**：-12, -6（基线）, -3, 0。

### 1.5 batch size B

- **是什么**：每次更新采样的 transition 数。
- **作用**：梯度噪声 ∝ 1/√B。
- **太小（16）**：梯度噪声大，critic 拟合抖。
- **太大（4096）**：噪声更小，但 UTD 固定时更新次数没变，所以**不会因此学得更快**；还会复用更多重复样本（buffer 前期很小）。
- **预期**：钝感。≥64 都落在噪声内；16 偏差（约 -20%～-40%）；4096 ≈ 基线。
  已观察到 batch 64/1024 与基线不可分，且这台机器上 batch 大小几乎不影响耗时（瓶颈是 kernel 启动，不是矩阵乘）。
- **网格**：16, 64*, 256（基线）, 1024*, 4096。

### 1.6 UTD（update-to-data ratio，每个环境步的更新次数）

- **是什么**：数据采集与梯度更新的比例。基线 1。
- **作用**：样本效率最直接的旋钮——同样的环境交互，多更新几次，数据被榨得更干。REDQ / DroQ 等工作把它推到 10–20，但同时需要更强的 critic 正则来防止高估。
- **太小**：更新赶不上数据，样本利用率低。
- **太大**：critic 在有限数据上过拟合、Q 高估、策略过早收敛（primacy bias），标准 SAC 在 UTD 很高时会变差。
- **预期**：UTD 2 在**每环境步**上比基线更好（早期 +20%～+40%，后期 +10%～+25%），这是本实验里**最有把握的正向效应**；UTD 4 早期继续领先，但后期增益递减，甚至不稳。
  代价：墙钟约 ×2 / ×4，所以**按墙钟比较时 UTD 2 不一定赢**。
- **网格**：1（基线）, 2, 4（tier 3，最慢）。

### 1.7 初始 alpha α0 与 alpha 学习率

- **α0**：温度初值。α 在自动调节下会被拉到由 H_target 决定的稳态，所以 α0 只影响**前期**。log α 每步最多变约一个学习率，
  α 从 1.0 降到 0.1 要 ≥7.7k 次更新。已有诊断：α0=1.0 造成约 20k 步延迟（策略均值接近 0，确定性评估几乎不动）。
- **alpha 学习率**：温度自适应的速度。小 → α 长期停在初值附近，熵偏离目标更久；大 → α 紧跟熵，可能来回振荡。
- **预期（α0）**：单调轻微衰减，全部在 1–2σ 内：0.001 ≈ 基线；0.1 ≈ -3%～-5%；1.0 ≈ -10%（已测）。
- **预期（alpha lr）**：3e-5 与 3e-4 差别很小（α 本来就变化不大）；3e-3 更噪但不坏。两者都在噪声内的概率较高。
- **网格**：α0 ∈ {0.001, 0.01（基线）, 0.1, 1.0*}；alpha lr ∈ {3e-5, 3e-4（基线）, 3e-3}。

### 1.8 网络宽度 hidden

- **是什么**：actor 与 critic 每层隐藏单元数（2 层）。
- **作用**：函数容量。HalfCheetah 的 obs 只有 17 维，容量压力小。
- **预期**：64 略低于基线（约 -10%～-25%，容量与优化都吃亏）；512 ≈ 基线（也可能略快，但在噪声内）。
  差别更可能出现在 1M 步，本实验看不到——这是 100k 预算的盲区。
- **网格**：64, 256（基线）, 512。

### 1.9 reward scale s

- **是什么**：critic 的 reward 目标除以 s（`reward / s`），评估回报仍记录原始值。
- **关键推导**：`s·y = r + γ(s·Q' − s·α·log π)`——等价于**把 reward 保持原样、温度放大 s 倍**。
  但 α 是自动调节的，会重新找到让熵达到 H_target 的稳态，所以**稳态解与 s 无关**；Adam 对损失的整体缩放近似不变。
  剩下的差别只有：(1) 初始温度相对 reward 的比值变了（有效 α0 = 0.01·s），(2) 数值尺度。
- **预期**：钝感，且应该被“初始 alpha 效应”解释：rs 5 ≈ α0 0.05（轻微延迟），rs 0.2 ≈ α0 0.002（≈ 基线）。
  **如果 rs 5 的下降明显大于 α0 1.0 的 -10%，说明上面的“自动调温抵消缩放”推导不成立，需要重新理解。**
- **网格**：0.2, 1（基线）, 5。

## 2. 实验协议

| 项 | 设置 |
| --- | --- |
| 环境 / 算法 | HalfCheetah-v5，SAC，2×256 MLP（与 `seed_experiments/halfcheetah_sac` 同代码） |
| 预算 | 100k env steps × 3 seeds（0/1/2），每 20k 步评估 5 回合（确定性 `tanh(μ)`，固定评估种子） |
| 基线 | 不重跑；取 1M 基线 run 的前 100k 步（同代码、同 seed、同评估网格） |
| 单因素 | 每次只改一个超参，其余保持基线 |
| 指标 | **后期** = 60k/80k/100k 三个评估点的均值；**早期** = 20k/40k 两个评估点的均值 |
| 噪声基准 | 基线后期回报的跨 seed 样本标准差 ≈ 9.7%（n=3） |
| 发散处理 | 参数出现 NaN/Inf 时记录 `diverged_at_step`，评估点补 NaN，图中标 ✕ |

网格共 29 个配置（已有 6 个，新增 23 个）× 3 seeds：

| tier | 内容 | 新增配置 | 估算耗时 |
| --- | --- | --- | --- |
| 1 | lr, γ, τ, target entropy, batch, UTD 2 | 14 | ≈ 4–5 h |
| 2 | α0, alpha lr, hidden, reward scale | 8 | ≈ 2–3 h |
| 3 | UTD 4（单 run 约 4 倍时长） | 1 | ≈ 1–2 h |

估算依据：6 个 run 并行时单 run 约 34 分钟（已实测），UTD 2 / 4 按 2×/4× 折算，总计 ≈ 81 个“run 等价”，约 7.5 小时。
这是估算，不是保证；调度按 tier → seed → 配置排序，**随时中断，已完成的都是整齐的前 k 个 seed**。

## 4. 怎么读灵敏度图

产物在 `results/`：`sensitivity_map.png`（后期）、`sensitivity_early.png`（早期）、`sensitivity_tornado.png`（排序）、
`sensitivity_summary.md`（逐超参一行）、`sensitivity_table.md/csv`（逐配置明细）。

- **灵敏度**：性能随超参（对数）移动的变化幅度，相对基线噪声（≈10%）衡量，**不是**“谁最好”。
- **敏感**：存在 ★ 点（3/3 seed 同号，且平均配对差 > 2 倍基线标准差）；这类超参要先调、不能乱动。
- **钝感**：所有点都在噪声内；按算力和习惯选，不值得花时间。
- **不对称**：往一边敏感、往另一边不敏感（如 lr：往小敏感、往大不敏感），这类需要成对理解。
- **早期 vs 后期**：两张图结论不同就是“更快但不更好”（如 lr 1e-3）。
- ★ 的门槛为什么不用 p 值：n=3（df=2）下对 ~28 个比较做多重比较校正几乎不可能通过；表里保留 p 和 Holm p 作参考，判定用效应量加方向一致性。

## 5. 局限（读结果前先记住）

1. 100k 步只看样本效率和上升速度，**不是**最终性能；hidden、target entropy 的差异大概率在 1M 才显现。
2. 3 个 seed：噪声约 10%，小于 20% 的差异基本不能下结论；★ 是“强线索”，不是“已证明”。
3. 单因素扫描看不到交互（lr×UTD、γ×α、reward scale×α0）；γ 与 reward scale 的解释都带 Q 尺度混杂。
4. 评估是确定性 `tanh(μ)`，对 α0、target entropy 这类改变策略方差的超参会放大“早期不动”的现象。
5. 一个环境、一份实现：这是 HalfCheetah 上这份 SAC 的灵敏度，不是“SAC 的灵敏度”。
6. 基线来自 1M run 的前 100k 步，和扫描 run 在同一代码路径上，但不是在同一批并发条件下跑的（对回报无影响，对耗时有）。
