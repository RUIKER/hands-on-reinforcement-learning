# 02 DQN 经验总结

> **算法编号**：02 / 11
> **算法家族**：深度 value-based（离散动作）
> **前驱算法**：01 表格型 Q-learning
> **后继算法**：03 Double DQN / Dueling DQN
> **一句话定位**：用神经网络代替 Q 表，并用 replay buffer 与 target network 让“神经 Q 学习”稳定下来，是深度强化学习的第一个里程碑。

## 算法定位：四个问题

### 这个算法的特点是什么

DQN 学习一个参数化的动作价值函数：

$$
Q_\theta(s,a)\approx Q^*(s,a)
$$

它有三个标志性组件：

1. **Q 网络**：输入状态，输出每个离散动作的 Q 值。
2. **Replay buffer**：把 `(s, a, r, s', done)` 存入经验池，随机采样 batch，打破连续样本的时间相关性。
3. **Target network**：用一份延迟更新的 `Q_target` 计算自举目标，避免“目标跟着当前网络一起动”。

损失函数：

$$
L(\theta)=\mathbb{E}_{(s,a,r,s')\sim\mathcal{D}}\left[\left(Q_\theta(s,a)-\left(r+\gamma(1-d)\max_{a'}Q_{\theta^-}(s',a')\right)\right)^2\right]
$$

行为策略通常是 ε-greedy：

$$
a=\begin{cases}
\text{随机动作}, & \text{以概率 }\varepsilon\\
\arg\max_a Q_\theta(s,a), & \text{否则}
\end{cases}
$$

### 它针对前驱算法的哪些缺陷

- **表格 Q-learning 无法扩展到高维状态**：Q 表大小为 `|S|×|A|`，图像或连续状态根本存不下；DQN 用神经网络泛化到未见过的状态。
- **朴素“神经网络 + Q-learning”不稳定**：连续样本高度相关、target 每步都变，二者与函数逼近一起构成“致命三要素”（deadly triad）。DQN 用 replay buffer 打散相关性，用 target network 固定一段时间内的回归目标，使训练可控。

### 局限性在什么地方

- **只能处理离散动作**：选动作需要 `argmax_a Q(s,a)`，动作必须是有限集合。连续动作要用 DDPG/TD3/SAC。
- **Q 值高估**：target 中的 `max` 会把估计噪声也最大化，导致 Q 值系统性偏高。这是 03 Double DQN 的出发点。
- **样本效率仍不算高**：虽然 replay 可以重复利用数据，但 DQN 通常需要大量环境交互。
- **训练不稳定、对超参数敏感**：学习率、replay 大小、target 同步频率、ε 调度都会显著影响结果。
- **无法自然表达随机策略**：学到的本质是确定性贪心策略，探索靠 ε-greedy 外加。
- **只适用于离散、低维动作空间**：动作维度增大时，输出层和 `argmax` 都会变贵。

### 典型应用场景有哪些

- Atari 等离散动作游戏，以及状态为图像/高维向量的离散决策任务。
- 推荐、排序、广告竞价等动作集合有限的业务决策。
- 资源分配、调度、离散控制。
- 作为深度 RL 的教学起点：理解 replay、target network、TD target 之后，再看 Double/Dueling、DDPG、SAC 会容易得多。

## 核心代码阅读

### Q 网络

```python
class Qnet(torch.nn.Module):
    def forward(self, x):
        x = F.relu(self.fc1(x))
        return self.fc2(x)          # 输出 [batch, action_dim]
```

输出的是**每个动作的 Q 值**，不是动作本身。选动作时再取 `argmax`。

### 动作选择

```python
if np.random.random() < self.epsilon:
    action = np.random.randint(self.action_dim)
else:
    action = self.q_net(state).argmax().item()
```

这就是 ε-greedy：以 ε 概率探索，否则利用当前 Q 网络。

### TD 更新

```python
q_values = self.q_net(states).gather(1, actions)       # 实际动作的 Q
max_next_q = self.target_q_net(next_states).max(1)[0]  # max over next actions
q_targets = rewards + gamma * max_next_q * (1 - dones)
loss = F.mse_loss(q_values, q_targets)
```

三个关键点：

1. `gather(1, actions)` 只取出实际执行动作对应的 Q 值。
2. `max_next_q` 来自 **target network**，不是 online network。
3. `(1 - dones)` 在真正终止时停止 bootstrap。

## 已知问题（练习代码）

`practice.py` 的 `update()` 中有一行：

```python
states = torch.tensor(transition_dict['rewards'], dtype=torch.float)
```

这里把 `rewards` 误写成了 `states`，是复制教程时的笔误，正确写法应为：

```python
states = torch.tensor(transition_dict['states'], dtype=torch.float)
```

这段练习代码也没有完整的训练入口，且部分工具函数仍使用旧版 Gym API。它的价值在于展示 DQN 的最小结构，不应直接拿来做实验。需要运行完整 DQN 系列，请使用 03。

## 从 DQN 到 03：两个改进方向

| 问题 | 改进 | 做法 |
| --- | --- | --- |
| `max` 导致 Q 值高估 | Double DQN | online network 选动作，target network 评估 |
| `V(s)` 和 `A(s,a)` 耦合 | Dueling DQN | 网络拆成价值流和优势流，再合成 Q |

这两项改进可以独立使用，也可以组合成 Dueling Double DQN。

## 在算法推进线上的位置

- **从哪来**：01 表格型 Q-learning。DQN 保留了它的 TD target 和 ε-greedy，只把 Q 表换成神经网络，并补上 replay 和 target network。
- **到哪去**：03 修正 Q 值高估和网络结构；更远的 09 DDPG 也直接继承 DQN 的 replay buffer + target network。
- **一句话记住**：DQN 的贡献不是“用了神经网络”，而是“用 replay 和 target network 让神经 Q 学习能稳定训练”。
