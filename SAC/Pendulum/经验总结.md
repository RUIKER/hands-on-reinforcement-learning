# SAC Pendulum 经验总结

## 1. SAC 的核心思想

SAC（Soft Actor-Critic）是 off-policy 最大熵强化学习算法。它同时追求：

1. 获得较高的环境回报。
2. 保持策略具有足够的熵，避免过早陷入单一动作。

SAC 使用一个随机 actor、两个 online critic 和两个 target critic。

## 2. Pipeline

```text
state
  -> Gaussian actor 采样 action 和 log_prob
  -> 环境交互
  -> replay buffer
  -> 随机采样 batch
  -> 计算 soft Bellman target
  -> 更新两个 critic
  -> 重参数化采样并更新 actor
  -> 更新 alpha
  -> soft update 两个 target critic
```

SAC 是 off-policy，因此可以重复利用 replay buffer 中的旧经验。

## 3. 高斯策略和重参数化

策略网络输出高斯分布参数：

$$
 u=\mu(s)+\sigma(s)\epsilon,\quad \epsilon\sim\mathcal{N}(0,I)
$$

这里使用 `Normal.rsample()`，而不是 `sample()`。`rsample()` 将随机性放到独立噪声 `epsilon` 中，使梯度可以穿过动作回到 actor 参数。

为了满足 Pendulum 的动作范围，先计算：

$$
 a=\tanh(u)
$$

再将 `[-1, 1]` 映射到环境动作区间。

`tanh` 会改变概率密度，因此 log probability 需要进行变量变换修正。当前实现修正的是 `tanh(u)` 的 Jacobian，并同时考虑动作缩放。

## 4. 双 Q 网络

两个 critic 分别估计：

$$
Q_1(s,a),\quad Q_2(s,a)
$$

目标值使用较小的一个：

$$
\min(Q_1,Q_2)
$$

这样可以缓解单个 Q 网络过高估计的问题。

Soft Bellman target 为：

$$
y=r+\gamma\left(\min_i Q_{target,i}(s',a')-\alpha\log\pi(a'|s')\right)(1-done)
$$

## 5. Actor、alpha 和 target critic 更新

Actor loss：

$$
L_{actor}=\mathbb{E}[\alpha\log\pi(a|s)-\min_iQ_i(s,a)]
$$

其中第一项鼓励保持熵，第二项鼓励选择高价值动作。

温度系数 `alpha` 使用 `log_alpha` 参数化：

```python
alpha = log_alpha.exp()
```

这样 alpha 始终为正。当前使用自动温度调节：

- 熵低于目标值：增大 alpha，鼓励探索。
- 熵高于目标值：减小 alpha，更关注回报。

目标熵通常设为：

```python
target_entropy = -action_dim
```

Target critic 使用软更新：

$$
\theta_{target}\leftarrow(1-\tau)\theta_{target}+\tau\theta
$$

## 6. 与原始示例的改进

1. 使用 `gymnasium` 和 `Pendulum-v1`，适配新版 `reset()`/`step()`。
2. 将网络、agent、trainer、replay buffer 和可视化拆分。
3. 使用 `Normal.rsample()` 实现正确的重参数化采样。
4. 修正 `tanh` 和动作缩放后的 log probability。
5. 使用两个 critic 和两个 target critic。
6. 自动学习温度系数 `alpha`。
7. 区分真实终止 `terminated` 与时间截断 `truncated`，避免错误停止 bootstrap。
8. 使用 NumPy 数组转换 tensor，避免列表构造带来的性能警告。

## 8. 教程结果对比

教程使用约 100 个 episode，Pendulum 末段平均回报约为 `-171.265`。当前实现应使用相同回合数、seed 和环境版本进行对比。

需要注意：

- 教程使用旧版 `Pendulum-v0`，当前使用 `Pendulum-v1`。
- Gymnasium 版本会影响初始状态和时间截断行为。
- SAC 的曲线也可能有波动，但通常比 DDPG 更稳定。
- 应观察最后 9 或 20 回合移动平均，而不是单个 episode。

建议至少使用 3 个随机种子，报告最后平均回报、最佳回报和标准差。

## 9. 本次实验结果

教程记录的 SAC Pendulum 参考结果是 100 回合末段平均回报约 `-171.265`。当前实现使用 `Pendulum-v1`、固定 seed=0，运行 100 回合后得到：

```text
最后 10 回合平均回报：-148.455
```

当前结果与教程处于同一量级，并略好于教程记录。由于教程使用旧版 `Pendulum-v0`，而当前使用 `Pendulum-v1`，同时 Gymnasium 版本和时间截断处理不同，不能把两个数字视为严格可重复的同一实验。

这次结果说明以下组件能够共同工作：

- replay buffer 能正确采样。
- `rsample()` 重参数化策略能正常反向传播。
- tanh 动作变换后的 log probability 修正有效。
- 双 Q 网络和 target critic 能完成更新。
- 自动温度系数 alpha 能从初始值开始学习。
