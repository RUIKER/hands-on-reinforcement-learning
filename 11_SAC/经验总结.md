# 11 SAC 经验总结

> **算法编号**：11 / 11
> **算法家族**：off-policy、最大熵、随机 actor-critic（连续动作）
> **前驱算法**：09 DDPG、10 TD3（确定性策略、探索脆弱）
> **后继方向**：本仓库之外的 model-based RL、offline RL、模仿学习与真实机器人部署
> **一句话定位**：把“探索”写进目标函数，用最大熵随机策略取代确定性策略，是连续控制中兼顾样本效率与稳定性的通用默认选择。

## 算法定位：四个问题

### 这个算法的特点是什么

SAC（Soft Actor-Critic）优化的是**带熵奖励的回报**：

$$
J(\pi)=\mathbb{E}_{\pi}\left[\sum_t \gamma^t\left(r_t+\alpha\mathcal{H}(\pi(\cdot|s_t))\right)\right]
$$

它同时维护：

- 一个随机高斯 actor `π_θ(a|s)`；
- 两个 online critic、两个 target critic；
- 一个可学习的温度系数 `α`。

Soft Bellman target 为：

$$
y=r+\gamma(1-d)\left(\min_{i=1,2}Q_{\phi_{i,\text{targ}}}(s',a')-\alpha\log\pi_\theta(a'|s')\right)
$$

两个 critic 都向 `y` 回归。Actor 的目标是：

$$
L_\pi=\mathbb{E}\left[\alpha\log\pi_\theta(a|s)-\min_{i=1,2}Q_{\phi_i}(s,a)\right]
$$

其中动作通过重参数化采样 `a = tanh(μ(s) + σ(s)⊙ε)` 得到，使梯度可以穿过随机采样。

### 它针对前驱算法的哪些缺陷

- **DDPG/TD3 的探索靠外加噪声**：确定性 actor 执行 `μ(s)+noise`，噪声尺度需要手动调；噪声太小探索不足，太大又会破坏已经学好的策略。
- **确定性策略容易过早收敛**：一旦 actor 塌缩到单一动作，后续数据都围绕这个动作，critic 也难以纠正。
- **TD3 仍然没有“探索”这一项**：它只修稳定性，不改变探索机制。

SAC 把熵直接放进目标：策略在追求高回报的同时，被鼓励保持一定随机性。温度系数 `α` 自动平衡“回报”和“探索”，不需要手动调探索噪声。双 Q 取最小则继承了 TD3 抑制高估的思路。

### 局限性在什么地方

- **网络和超参数更多**：actor、两个 critic、两个 target critic、`log_alpha` 优化器；初始 `α`、目标熵、reward scale 都会影响结果。
- **对奖励尺度敏感**：Pendulum 的奖励范围约为 `[-16, 0]`，当前实现用 `REWARD_SHIFT=8`、`REWARD_SCALE=8` 只缩放 critic 目标；换环境时必须重新检查 reward scaling。
- **仍是 off-policy 非凸优化**：没有收敛保证，训练仍可能不稳定；双 Q 只能缓解、不能消除高估。
- **连续动作实现更复杂**：tanh 变换后要修正 log probability 的 Jacobian，动作维度上要对 log probability 求和。
- **有额外的计算成本**：每个 step 更新两个 critic、一个 actor 和一个温度系数，wall-clock 比 DDPG 慢。
- **离散动作需要单独版本**：标准 SAC 面向连续动作；离散 SAC 要把高斯策略换成 Categorical，并重新推导熵项。

### 典型应用场景有哪些

- 机器人 locomotion、 manipulation、抓取等连续控制任务。
- 采样成本高的真实系统：SAC 的 off-policy replay 和最大熵探索通常比 on-policy 方法更省样本。
- 需要鲁棒策略的场景：熵正则让策略对扰动和初始状态更不敏感。
- 作为连续控制的默认 baseline：在不知道选什么算法时，SAC 往往是第一个值得尝试的选择。
- 与 TD3 并列作为“DDPG 之后”的两条路线：TD3 修稳定性，SAC 换探索框架。

## Pipeline

```text
state
  -> 高斯 actor 采样动作和 log_prob
  -> 环境交互
  -> replay buffer
  -> 随机采样 batch
  -> 计算 soft Bellman target（双 Q 取最小，减去 alpha * log_prob）
  -> 更新两个 critic
  -> 重参数化采样并更新 actor
  -> 更新温度系数 alpha
  -> 软更新两个 target critic
```

详细推导和本案例的实现细节见 [`Pendulum/经验总结.md`](Pendulum/经验总结.md)。

## 与 DDPG、TD3 的对照

| 维度 | DDPG | TD3 | SAC |
| --- | --- | --- | --- |
| 策略 | 确定性 | 确定性 | 随机高斯 |
| 探索 | 外加 Normal/OU 噪声 | 外加 Gaussian 噪声 | 策略熵 + 自动温度 |
| Critic 数量 | 1 | 2 | 2 |
| Q 值高估 | 无专门处理 | 双 Q 取最小 | 双 Q 取最小 |
| Target 稳定性 | 软更新 | 软更新 + smoothing + 延迟 | 软更新 + 熵项 |
| 每步更新 | actor + critic | critic 每步、actor 延迟 | actor + 2 critic + alpha |
| 主要优势 | 简单、样本效率高 | 比 DDPG 稳 | 探索有原则、鲁棒 |
| 主要代价 | 脆弱 | 两个 critic | 组件多、reward scale 敏感 |

## 实验结果（Pendulum）

`11_SAC/Pendulum` 使用 100 回合训练，固定种子，得到最后 10 回合平均回报约 `-148.455`。教程中的 SAC Pendulum 参考值约为 `-171.265`，当前结果处于同一量级并略好。

需要注意：

- 教程使用旧版 `Pendulum-v0`，当前使用 `Pendulum-v1`，数值不能严格对齐。
- 该结果记录的是**带探索的训练回报**；不同算法间比较应使用统一的确定性/随机策略评估协议。
- 单个种子不能代表算法稳定性，建议用 3–5 个种子报告均值和标准差。

更完整的实现细节、alpha 自动调节和排错记录见 [`Pendulum/经验总结.md`](Pendulum/经验总结.md)。

## 在算法推进线上的位置

- **从哪来**：09 DDPG 提供 off-policy 连续控制框架，10 TD3 提供双 Q 抑制高估；SAC 在此基础上把确定性策略换成最大熵随机策略。
- **到哪去**：本仓库的 RL 主线到此结束。后续可以沿三个方向扩展：
  - **model-based RL**：学习环境模型，提高样本效率；
  - **offline RL**：只从固定数据集学习，不与环境交互；
  - **模仿学习**：从专家示范中学习策略，不再依赖环境奖励。
- **一句话记住**：DDPG 解决了“连续动作能不能学”，TD3 解决了“学得稳不稳”，SAC 解决了“探索有没有原则”。
