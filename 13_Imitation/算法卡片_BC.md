# BC 算法卡片

> 全称：Behavior Cloning
> 一句话：把专家示范当成监督数据，直接回归 `π(a|s)`。

## 1. 解决什么问题

真机 RL 采样太贵、探索危险，所以先用专家示范训一个策略作为起点。

## 2. 核心公式

专家给出数据集 `D = {(s_i, a_i)}`，训练目标是最大化专家动作的似然：

```
θ* = argmax_θ Σ_i log π_θ(a_i | s_i)
```

当 `π_θ` 是确定性高斯、方差固定时，等价于最小化均方误差：

```
L(θ) = E_(s,a)~D [ ||π_θ(s) − a||² ]
```

代码里用 MSE 不是随手选，它就是 MLE 在固定方差下的形式。

## 3. 两个经典失败

### 3.1 Compounding error（误差累积）

- 训练时策略只在专家访问过的状态上被监督；
- 自己跑 rollout 时，小误差会让下一状态偏离示范分布；
- 新状态下策略更容易出错，误差又被放大。

DAgger 论文的误差界是 `O(T²ε)`：单步误差 `ε` 会在 `T` 步内二次放大。

### 3.2 多模态动作被平均

同一观测下有多个合理动作时（如左右绕过障碍），单峰高斯会把它们平均成一个错误动作。

本目录的 `corridor` 任务专门隔离这个现象：专家随机走上绕或下绕，BC 学到的是直走撞墙。

## 4. 什么时候用、什么时候不用

| 适合 | 不适合 |
|---|---|
| 数据多、专家强、任务误差可自我纠正 | 数据少、分布偏移大、需要多模态动作 |
| 快速拿到一个能跑的策略 | 要求长期 rollout 稳定 |

## 5. 与 RL 的关系

- BC 是**开环模仿**：只学专家怎么做，不学习环境奖励。
- RL 可以在线修正 BC 策略：先用 BC 初始化，再用 RL fine-tune（如 DAPG、AW-Opt）。
- 面试追问："BC 初始化 + RL fine-tune 为什么比从零 RL 好？"——样本效率更高，前期不掉进随机探索的坑里。

## 6. 面试一句话

"BC 把专家示范当监督学习，用 MLE 训策略。它有两个硬伤：误差在 rollout 中会累积，多模态动作会被单峰分布平均。ACT 和 Diffusion Policy 分别用 action chunking 和扩散模型解决这两个问题。"
