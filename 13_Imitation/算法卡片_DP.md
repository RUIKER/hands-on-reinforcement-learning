# Diffusion Policy 算法卡片

> 论文：Diffusion Policy: Visuomotor Policy Learning via Action Diffusion (Chi et al., 2023)
> 一句话：用**扩散模型**直接建模动作的条件分布，替代 BC/ACT 里的高斯或 CVAE。

## 1. 解决什么问题

| 上一代的局限 | Diffusion Policy 的对策 |
|---|---|
| BC 单峰高斯：多模态动作被平均 | 扩散模型天然是多峰分布的通用逼近器 |
| CVAE：表达力仍有限，latent 维度需设计 | 不需要显式 latent，通过去噪过程覆盖复杂分布 |
| ACT：仍是 MSE 重构，动作空间受限 | 支持任意连续动作分布，可建模强相关多步动作 |

## 2. 核心思想

把生成图像的扩散模型搬到动作生成：

```text
训练：
  从示范动作 a^0 开始
  逐步加噪声得到 a^K ~ N(0, I)
  网络 ε_θ(a^k, k, obs) 学习预测所加的噪声

推理：
  从随机噪声 a^K ~ N(0, I) 开始
  多步去噪：a^{k−1} = a^k − α · ε_θ(a^k, k, obs)
  最终得到动作 a^0
```

观测作为去噪网络的条件，全程不参与扩散过程。

## 3. 关键公式

训练目标（DDPM 简化版）：

```
L = E_{a^0, k, ε} [ || ε − ε_θ( √(ᾱ_k) · a^0 + √(1−ᾱ_k) · ε, k, obs ) ||² ]
```

- `a^0`：示范动作
- `k`：扩散步，从均匀分布采样
- `ε`：标准高斯噪声
- `ε_θ`：去噪网络

推理时 DDIM 加速：

```
a^{k−1} = √(ᾱ_{k−1}) · (a^k − √(1−ᾱ_k) · ε_θ) / √ᾱ_k + √(1−ᾱ_{k−1}) · ε_θ
```

可以把 1000 步 DDPM 压缩到 10–50 步，牺牲少量质量换速度。

## 4. 网络结构

- 观测编码器：CNN / ViT 提取视觉或状态特征
- 去噪网络：
  - 输入：带噪动作 `a^k`、步数 `k`、观测特征
  - 输出：预测噪声 `ε_θ`
- 常见选择：MLP、1D CNN、Transformer（如 Diffusion Policy 原版的 U-Net 1D）

## 5. 什么时候会失败

| 失败模式 | 原因 | 面试追问 |
|---|---|---|
| 推理慢 | 需要多步去噪，实时控制对延迟敏感 | 你用什么加速？DDIM 多少步？ |
| 需要大量数据 | 扩散模型容量大，小数据集容易过拟合 | 你有多少条示范？ |
| 动作维度高时计算贵 | 每步都要做一次网络前向，动作序列长时显存/时间增长 | 动作块长度和模型输入长度怎么定？ |
| 超出训练分布 | 仍是监督学习，测试时动作分布偏移会失效 | 怎么缓解 compounding error？（常见：加 action chunking） |

## 6. 与 ACT 的对比

| 维度 | ACT | Diffusion Policy |
|---|---|---|
| 分布建模 | CVAE（隐变量） | 扩散模型（去噪） |
| 多模态 | 靠 latent | 靠扩散过程本身 |
| 训练目标 | MSE 重构 + KL | 噪声预测 MSE |
| 推理 | 单步前向 | 多步迭代 |
| 延迟 | 低 | 高（需 DDIM 加速） |
| 表达力 | 较强 | 更强 |

实际中经常把两者结合：**Diffusion Policy 也做 action chunking**，一次生成多步动作，只执行第一步。

## 7. 面试一句话

"Diffusion Policy 把动作生成当成条件扩散：训练时网络学习从加噪动作中预测噪声，推理时从纯噪声多步去噪得到动作。它比高斯和 CVAE 更能表达多模态动作分布，代价是推理需要多步迭代，所以用 DDIM 加速，并且通常配合 action chunking 使用。"
