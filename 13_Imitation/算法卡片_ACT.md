# ACT 算法卡片

> 论文：Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware (Zhao et al., 2023)
> 一句话：用 **Action Chunking** 抑制误差累积，用 **CVAE** 解决多模态动作被平均。

## 1. 解决 BC 的哪两个失败

| BC 失败 | ACT 对策 | 直观解释 |
|---|---|---|
| **Compounding error** | Action Chunking | 一步只执行预测序列的第一个动作，下一时刻重新观测并重新预测。单步误差不会一路滚雪球 |
| **多模态动作被平均** | CVAE 学习条件动作分布 | 同一观测下可以有多条合理轨迹（如从左/右绕过障碍），单峰高斯会平均成错误动作；CVAE 用隐变量覆盖多个模态 |

## 2. 核心结构

```text
观测编码器（ResNet / ViT）
      ↓
  观测特征 z_obs
      ↓
┌─────────────────────────────────────┐
│ CVAE：在训练时 encoder 把动作序列    │
│        编码成隐变量 z，decoder 用    │
│        z_obs + z 重构动作序列        │
│ 推理时：z = 0（只用均值）            │
└─────────────────────────────────────┘
      ↓
  动作块（action chunk）：k 步动作
```

### 2.1 Action Chunking

- 训练目标：给定当前观测，预测未来 `k` 步动作 `a_t, a_{t+1}, ..., a_{t+k-1}`。
- 执行：只用 `a_t`，下一时刻重新观测并重新预测。
- 为什么能降低 compounding error：
  - 单步策略的误差会改变下一状态，策略在训练分布外越来越差；
  - Chunking 相当于每 `k` 步"重启"一次规划，误差最多累积 `k` 步就被截断。

### 2.2 CVAE

- 训练：最小化重构损失 + KL 散度，和 VAE 一样。
- 推理：**把 latent 置 0**，即只用分布的均值；不需要采样多个 z。
- 多模态：不同训练轨迹对应不同的 latent，decoder 学会"同一个观测 + 不同 z → 不同动作序列"；
  推理时 z=0 是多个模态的某种折中，但比单峰 MSE 更能覆盖多峰分布。

## 3. 关键公式

训练损失：

```
L = E_{q(z|a_{t:t+k}, o_t)} [ ||a_{t:t+k} − decoder(z, o_t)||² ]
    + β · D_KL( q(z|a_{t:t+k}, o_t) || N(0, I) )
```

推理：

```
â_{t:t+k} = decoder(z=0, o_t)
执行 â_t，丢弃 â_{t+1:t+k−1}
```

## 4. 什么时候会失败

| 失败模式 | 原因 | 面试追问 |
|---|---|---|
| 反应变慢 | 每次预测 k 步，模型前向一次；k 越大，单次计算量越大 | 你选的 k 是多少？怎么权衡延迟与稳定性？ |
| 未见过的观测泛化差 | 仍然是监督学习，训练分布外的状态会崩溃 | 和 BC 一样，需要 DAgger 或在线修正 |
| latent_dim 太小 | 无法覆盖所有模态；太大 | 你如何选 latent_dim？ |
| z=0 不是最佳 | 多模态严重不平衡时，均值可能落在低概率区域 | 推理时为什么不采样多个 z？ |

## 5. 与 BC 的关系

- ACT 的底层仍是 MLE：最大化示范动作的对数似然。
- 它改的是**动作表示**（chunk）和**分布建模**（CVAE），不是训练目标。
- 因此：训练数据不足、分布偏移大时，ACT 也会失败，只是失败形态和 BC 不同。

## 6. 面试一句话

"ACT 在 BC 上加了两样东西：action chunking 把单步策略的误差累积截断成短窗口，CVAE 把单峰高斯扩成多模态条件分布；推理时 CVAE 的 latent 置 0，不需要采样。"
